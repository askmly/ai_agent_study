# 第 2 周总结（Day8-Day13）

## 本周主题
AI 编程工具 + LLM 核心概念 + API 调用 + Prompt 工程 + 结构化输出

## 完成内容
- Day8：Cursor 上手，用 Cursor 重写通讯录
- Day9：AI 编程工作流，给待办清单加保存/读取
- Day10：LLM 核心概念，注册 DeepSeek API，拿 Key
- Day11：第一个 API 调用，多轮对话脚本
- Day12：Prompt 工程，三个场景 + JSON 结构化输出
- Day13：Prompt 优化，第 2 周整理，代码调用 AI 做意图分类

## 核心技能
- 会用 Cursor 的 Tab / Ctrl+K / Ctrl+L / Ctrl+I
- 理解 LLM、API、Token、Prompt、Context Window
- 会调用 LLM API，维护多轮对话
- 会写 System Prompt、Few-shot、输出约束
- 会让模型输出 JSON 并用 `json.loads` 解析
- 会处理 API 异常、超时、重试

## 产出物
- `first_call.py`：第一个 API 调用

- `prompt_scenes.py`：三个 Prompt 场景
